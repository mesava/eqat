# Первый проход проверки источников и SOP v0.3

Статус: редакторские черновики, не для выполнения на оборудовании. Исходные v0.2 и активные ссылки генератора не изменены.

Проверены отдельные утверждения для 31 приоритетного теста. Для остальных 130 создана явная очередь NOT_REVIEWED. Общая оценка каждого теста остаётся UNRESOLVED: подтверждение частоты/предела не подтверждает полную методику.

VERIFIED — только конкретное утверждение ниже; LOCALLY_DERIVED — локальное решение; UNRESOLVED — недостаточно доказательств; CONTRADICTION зарезервирован для доказанного противоречия (в этом проходе не назначен).

23 содержательных черновика (включая восемь дополнений анализа) и восемь заблокированных карточек заводских процедур. Карточка без шагов не считается завершённой SOP. Все 31 требуют QMP review и локальной валидации.

Номера страниц ниже — физические PDF-страницы с 1. Для MPPG2.b печатная страница = PDF + 72; TG198 = e(829 + PDF); TG302 = e(81 + PDF). Полные тексты PDF и частные ссылки в Git не включены.

## Результаты и черновики

### MLC-D1 — Ежедневный паттерн SRS

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

0,5 мм подтверждены. Таблица рекомендует разработать упрощённую ежедневную проверку; минимум количественной проверки — еженедельно. Это не готовый ежедневный алгоритм.

Источники: MPPG9B, PDF 12, Table 1, MLC position accuracy; MPPG8B, PDF 21,22, 8.2.6 MLC2

**Входной шаблон:** Согласованный паттерн; энергия; угол; масштаб EPID; координаты всех проверяемых лепестков; эталонный сдвиг.

**Предложенные действия:** Проверить версию QA-плана и геометрию детектора → получить изображение паттерна по утверждённому локальному маршруту → измерить позиции независимым алгоритмом → сохранить полный список ошибок и контроль чувствительности.

**Анализ:** e_i=x_measured,i−x_planned,i; E=max|e_i|. Для качественного варианта документировать обнаружение валидированного эталонного отклонения; не выводить численный PASS из визуальной оценки.

**Открыто:** Выбрать и валидировать ежедневный паттерн и чувствительность, режим SRS и независимый способ измерения.

### MLC-W1 — Количественный анализ положений

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Еженедельная количественная проверка всех лепестков, 0,5 мм, разные углы/дуга; одни логи недостаточны. Исключение допуска требует письменного решения производителя и QMP.

Источники: MPPG8B, PDF 14,21,22, Table 8; 8.2.6 MLC2

**Входной шаблон:** Плановые/измеренные координаты; bank/leaf ID; масштаб в изоцентре; углы; baseline.

**Предложенные действия:** Сопоставить каждый лепесток и позицию с планом → проверить знак и масштаб → рассчитать ошибки по всем углам → вывести пропуски покрытия → сравнить максимум, среднее и SD с предыдущими сеансами.

**Анализ:** e_ijk=x_measured,ijk−x_planned,ijk; E=max|e_ijk|; bias=mean(e); SD=sample_sd(e). Непокрытый лепесток не считать прошедшим.

**Открыто:** Конкретный угловой цикл и анализ Agility должны быть локально валидированы.

### MLC-M1 — Точечная доза комплексного плана

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Ежемесячная комплексная проверка VMAT/sliding-window: точечная доза относительно TPS, 2%; возможна одна энергия. Примечание допускает 1% от достигнутого при commissioning в соответствующем контексте. Gamma не заменяет точечную дозу.

Источники: MPPG8B, PDF 22,23, 8.2.6 MLC3; note to 8.3

**Входной шаблон:** ID плана/phantom; энергия; точка и объём detector ROI; D_TPS; показания, MU, поправки, калибровка.

**Предложенные действия:** Выбрать клинически представительный QA-план и точку с низким градиентом → сопоставить геометрию измерения и TPS → получить исправленную дозу → сравнить точечную дозу → распределение анализировать отдельно.

**Анализ:** delta_D=100*(D_measured/D_TPS−1). D_TPS>0; поправки и усреднение по объёму детектора должны быть валидированы. Gamma не заменяет delta_D.

**Открыто:** Выбрать план, фантом, малый детектор и точку; общей процедуре нужны отдельные результаты двух кодов.

### MLC-M2 — Скорость и динамические ошибки

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **UNRESOLVED**.

TG-198 описывает оценку скорости по положениям и времени и допуск ±0,5 см/с для теста максимальной скорости. Average Actual Error, Actual Tolerance и PRF требуют Elekta eCAT.

Источники: TG198, PDF 32,33, 2.F.2.3

**Входной шаблон:** Время; позиции; единицы; заданная скорость; frame rate; признак паузы; vendor field definitions.

**Предложенные действия:** Проверить монотонность времени и полное покрытие → выделить участки постоянной скорости и переходные процессы → рассчитать скорости и ошибки → отдельно перечислить паузы → поля eCAT трактовать только после проверки документа.

**Анализ:** v_i=(x_i+1−x_i)/(t_i+1−t_i); dt>0. Сопоставлять модуль скорости с заданным на том же участке. Пропуски кадров и разгон не включать в plateau без обоснования.

**Открыто:** Нужна применимая редакция VMAT eCAT §3.2.3 и определения полей журналов; TRF не подтверждает дозиметрию.

### MLC-M3 — Геометрия радиационного изоцентра

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

SRS 1 мм и SBRT 1,5 мм подтверждены; ежедневные проекции и ежемесячное 3D-смещение — разные метрики. Обычная RT: отдельный критерий диаметра 2 мм.

Источники: MPPG9B, PDF 12, Table 1, radiation isocentricity; MPPG8B, PDF 19,20,22, M11; MLC4

**Входной шаблон:** Изображения; калибровка; углы; координаты BB и поля; режим SRS/SBRT/обычная RT; алгоритм 3D.

**Предложенные действия:** Оценить центр мишени и поля на каждой проекции → записать 2D-векторы → для полного месячного набора выполнить валидированную 3D-реконструкцию → оценить покрытие углов и остатки fit → отдельно сохранить размер изоцентра.

**Анализ:** d2=sqrt(dx²+dy²); d3=sqrt(dx²+dy²+dz²) только после валидированной реконструкции. Максимум 2D расстояний не равен восстановленному d3; диаметр нельзя сравнивать с пределом радиуса.

**Открыто:** Не смешивать радиус, диаметр, 2D-проекцию и 3D-смещение; валидировать реконструкцию.

### MLC-A1 — Факторы выхода малых полей

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Для SRS/SBRT >1 см: 2% от TPS; ≤1 см: 5%. MLC1 предусматривает ежегодную проверку малого поля. Нужны поправки малого поля, а не только отношение показаний.

Источники: MPPG9B, PDF 12, Table 1, relative output factors; MPPG8B, PDF 14,21, Table 8; MLC1

**Входной шаблон:** Размеры полей; detector ID; corrected readings; MU; reference field; k_small/reference; TPS factors.

**Предложенные действия:** Проверить пригодность детектора и геометрию → применить подтверждённые поправки малого поля → вычислить OF → сопоставить TPS в той же геометрии → разделить группы апертур.

**Анализ:** OF=(M_small/MU_small)/(M_ref/MU_ref)*k_small/reference; delta=100*(OF/OF_TPS−1). Поправки не назначать равными 1 без обоснования.

**Открыто:** TRS-483/TG-155 и применимые поправки конкретного детектора ещё не проверены.

### MLC-A2 — Трансмиссия и две базы сравнения

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

TG-198: отклонение ±0,5 процентного пункта от baseline (пример 1,5% → 1–2%). MPPG9.b: 5% относительно TPS. Это разные сравнения.

Источники: TG198, PDF 33, 2.F.3.1; MPPG9B, PDF 12, Table 1, MLC transmission

**Входной шаблон:** Open/closed corrected readings; MU; энергия; положение камеры; T_baseline; T_TPS.

**Предложенные действия:** Проверить отсутствие стыка лепестков над камерой и отсутствие насыщения → нормировать показания на MU → рассчитать transmission → вывести разность процентных пунктов и относительную разность отдельно.

**Анализ:** T_percent=100*(M_closed/MU_closed)/(M_open/MU_open); delta_pp=T_percent−T_baseline_percent; delta_TPS_percent=100*(T_percent/T_TPS_percent−1). Нулевой T_TPS делает относительное сравнение неопределённым.

**Открыто:** Проверить модель TPS, геометрию, диапазон прибора и измерение inter-/intraleaf transmission для Agility.

### MLC-A3 — Абсолютные позиции и повторяемость

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **LOCALLY_DERIVED**.

TG-198 подтверждает повторяемость 1 мм как максимальную разность повторных положений. Годовое объединение с полной проверкой абсолютной позиции и 0,5 мм — локальная конструкция.

Источники: TG198, PDF 34, 2.F.3.2; MPPG8B, PDF 21,22, MLC2

**Входной шаблон:** Позиции по bank/leaf; запланированные координаты; серия повторов; углы; покрытие полного хода.

**Предложенные действия:** Сохранить отдельные серии абсолютной позиции и повторов → проверить неподвижность reference → для каждого лепестка вычислить ошибку, диапазон и SD → оценить каждый критерий отдельно.

**Анализ:** e_ij=x_ij−x_plan,i; range_i=max_j(x_ij)−min_j(x_ij). Повторяемость проверять по диапазону, а не по SD; низкий SD не доказывает абсолютную точность.

**Открыто:** Зафиксировать точки хода, число повторов, покрытие всех лепестков и углы.

### MLC-X1 — Диагностический набор FullPackage

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **LOCALLY_DERIVED**.

Общие проверки малых полей и точечной дозы не валидируют весь набор FullPackage и его локальные диагностические отношения.

Источники: MPPG8B, PDF 21,22, MLC1–MLC3

**Входной шаблон:** Версии 35 полей; энергия; референс 10x10; ROIs; baseline; исправленные дозы; векторы профилей.

**Предложенные действия:** Проверить reference dose → затем последовательно оценить малые поля, junction/gap/transmission, динамику и VMAT → сохранять отдельный результат каждого поля и метрики → исключить автоматическую настройку MLC/TPS.

**Анализ:** Нормировать только на валидный reference; отношения W/S/V определять для одинаковых ROI, MU и геометрии. Общий gamma-score не заменяет покомпонентные метрики.

**Открыто:** Нужны оригинальная инструкция FullPackage, планы, baseline и чувствительность каждого поля; универсальный gamma-порог не установлен.

### DOS-M2 — Постоянство OAF

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Ежемесячно: обзор ежедневных off-axis измерений либо отдельное измерение; 2% от device baseline. Это не ежегодное сравнение профиля с TPS.

Источники: MPPG8B, PDF 13,15, Table 4 D2; 8.2.2 D2

**Входной шаблон:** Энергия; прибор; координаты точек; M_axis; M_offaxis; baseline OAF; геометрия.

**Предложенные действия:** Выбрать обзор полноценных ежедневных данных или отдельное измерение → подтвердить охват энергий и направлений → проверить совпадение геометрии → рассчитать отклонения каждой точки → отдельно сохранить тренд симметрии.

**Анализ:** OAF_i=M_i/M_axis; delta_i=100*(OAF_i/OAF_baseline,i−1). Нулевые/отсутствующие знаменатели → NOT_EVALUATED.

**Открыто:** Определить нормировку, координаты, охват энергий и baseline; FFF не оценивать по произвольной плоскостности.

### DOS-A9 — Зависимость выхода от мощности

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Ежегодно проверяется клинический диапазон дозовых мощностей, 2% относительно мощности при калибровке.

Источники: MPPG8B, PDF 13,17, Table 4 D8; 8.2.2 D8

**Входной шаблон:** Энергия; dose rate; MU; corrected M; reference dose rate при калибровке; геометрия.

**Предложенные действия:** Согласовать весь клинический диапазон FF/FFF → использовать неизменную геометрию → измерить reference до и после серии → рассчитать относительный выход каждой мощности → проверить дрейф.

**Анализ:** q_r=M_corrected,r/MU_r; delta_r=100*(q_r/q_ref−1). При дрейфе reference расследовать стабильность до интерпретации мощности.

**Открыто:** Зафиксировать калибровочную мощность, диапазон FF/FFF, MU и пригодность детектора.

### DOS-Q1 — Перекрёстная проверка приборов

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **LOCALLY_DERIVED**.

Подтверждена привязка вторичных/ежедневных приборов к первичной калибровке. Конкретный график QuickCheck и порог межприборного отношения этим фрагментом не подтверждены.

Источники: MPPG8B, PDF 15, 8.2.2 D1, secondary/tertiary systems

**Входной шаблон:** Приборы и calibration IDs; matched beam conditions; corrected q_device/q_ref; baseline ratio; uncertainties.

**Предложенные действия:** Сопоставить приборы с валидированной первичной системой в воспроизводимой геометрии → получить повторные измерения → проверить дрейф и неопределённость → сохранить отдельные коэффициенты для энергий и приборов.

**Анализ:** R=q_device/q_ref; drift=100*(R/R_baseline−1). Для некоррелированных величин u_rel(R)=sqrt(u_rel(device)²+u_rel(ref)²); при общей калибровке учитывать ковариацию. Порог утверждается локально.

**Открыто:** Проверить TRS-398 Rev.1 и IFU приборов; определить неопределённость и график локально.

### MEC-M5 — Физическая гратикула

Источники: MPPG8B, PDF 13,19, Table 5 M7; 8.2.3 M7

**Анализ:** e_i=x_graticule,i−x_reference,i; масштаб проекции документировать; E=max|e_i| в согласованной плоскости.

**Открыто:** Уточнить наличие физической гратикулы и плоскость измерения.

### ACC-M2 — Положение внешнего клина

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **VERIFIED**.

Внешний физический клин: ежемесячно, повторяемость 1 мм именно в плоскости лотка. Не относится автоматически к внутреннему клину.

Источники: MPPG8B, PDF 14,21, Table 7 W2; 8.2.5 W2

**Входной шаблон:** Wedge/tray/slot IDs; reference marks; measured offsets at tray; latch condition.

**Предложенные действия:** По IFU установить каждый применяемый внешний клин → проверить фиксацию и метки клина/лотка/слота → измерить отклонения в плоскости лотка → повторную установку выполнять только по разрешённому маршруту.

**Анализ:** delta_i=x_i−x_reference,i в мм на лотке. Не переносить 1 мм в изоцентр без преобразования и отдельного основания.

**Открыто:** Подтвердить наличие и идентификаторы клиньев, лотков и разрешённый способ установки.

### ACC-U1 — Осмотр перед применением

**DRAFT_FOR_QMP_REVIEW**. Частная оценка: **UNRESOLVED**.

Источники описывают периодический контроль кодирования и блокировок аппликаторов. M12 — ежегодная проверка, а не готовая процедура перед каждым пациентом.

## Общие условия review

До выполнения QMP должен утвердить применимость, оборудование, геометрию, покрытие режимов/энергий, алгоритм и чувствительность, baseline, критерий и правило неопределённости. Все формулы выше — локальные аналитические предложения; ссылка на рекомендацию не означает, что она содержит именно эту реализацию.

Сохранять исходные данные и checksum, версии машины/плана/SOP/критерия/алгоритма, оператора и reviewer, калибровки, baseline, повторы, неопределённость и обоснование решения. Нет данных или утверждения — NOT_EVALUATED. Нельзя заменять отсутствующие измерения нулём или назначать PASS.

При отклонении проверить единицы, масштаб, геометрию, калибровку и привязку данных. Сохранять исходный отказ и все повторы; передать QMP/сервису. Эти черновики не разрешают изменение MLC/TPS, bypass interlocks или сервисных настроек.

Особые замечания: MPPG2.b §§4.4.15–4.4.21 описывают геометрию и дозу, а не процедуру gating interlock. В TG198 извлечённый текст содержит скрытые посторонние фрагменты TG219; страницы 33–34 проверены визуально и использованы только видимые разделы TG198. Месячный SAF-M5 не считать заменой ежедневного IMG-D1 без карты охвата.
