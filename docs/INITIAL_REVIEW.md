# Локальная проверка исходного пакета

Дата: 2026-11-14. Пакет: EQAT_KnowledgeBase_WorkPack_v0_2.zip.

## Результаты

- Все 9 исходных автоматических тестов прошли на Python 3.11.
- Генератор успешно создал отдельный предварительный результат в outputs/.
- В JSON и листе «Матрица 161» таблицы EQAT_SOP_Traceability_v0_2.xlsx совпали 161 уникальный код и 19 сопоставленных полей каждой записи: код, название, категория, частота, применимость, оборудование, измеряемая величина, предупреждение, предел, baseline, класс автоматизации, модуль, инструменты, замечание о валидации, приоритет, цель, действия при отказе, после сервиса, примечания.
- Для каждого теста проверено соответствие кода указанной строке исходного реестра FullPackage. Исходная книга содержит 71 лист; таблица прослеживаемости — 14.
- Для 161 SOP-карточки совпали 14 сопоставленных полей листа «SOP 161», включая подготовку, шаги, анализ, сохраняемые данные, решение и ссылки. Ссылки на идентификаторы версий между тестами и SOP согласованы.
- Все 35 записей FullPackage совпали с листом «FullPackage Agility» исходной книги по всем 14 полям. Они хранятся отдельно от реестра тестов.
- Статусы SOP: 130 черновиков требуют проверки источников; у 8 нет раздела анализа; для 23 требуется авторство. Клиническое утверждение отсутствует.

## Границы проверки

Код, JSON и исходные документы проекта сохранены без изменения методического содержания. Численные критерии не проверялись по первоисточникам. Клиническая валидация, полный аудит JSON Schema и реализация утверждения/расписания не выполнялись. Проект остаётся офлайн-прототипом, а архитектурные документы описывают будущую систему.

После первоначальной сверки частные ссылки на Google Drive вынесены в локальный файл local_sources/private_source_links.json, исключённый из Git. В test_definitions.json, sop_versions.json и source_registry.json соответствующие значения URL заменены на null. Библиографические названия и методическое содержание сохранены. Исходные ссылки также сохранены в локальном архиве. Поэтому отсутствие URL в публичных данных является намеренным отличием от исходных таблиц. Проверка текстовых файлов не является гарантией отсутствия всех возможных конфиденциальных сведений.

Excel, архив, справочные документы, локальные материалы проверки и результаты генератора исключены из Git через .gitignore. GitHub Actions настроен на исходные тесты и запуск генератора; на GitHub пока не запускался. Исходный manifest.json оставлен как манифест полученного пакета.
